# GFL2 Character Browser (VN)

<p align="right"><b>Tiếng Việt</b> · <a href="./GFL2_CHARACTER_BROWSER.html">English version</a></p>

Web tra cứu **offline** cho *Girls' Frontline 2: Exilium* (bản Global): **64 nhân vật + 187 vũ khí** —
kỹ năng, Neural Helix / Vertebrae, review, vũ khí đề xuất và **đội hình đề xuất** cho từng nhân vật
(meta / budget / boss, kèm thay thế F2P).

- **🌐 Dùng ngay:** <https://lamtehe7-hash.github.io/gfl2-vn/>
- **🇬🇧 Bản tiếng Anh:** <https://lamtehe7-hash.github.io/gfl2-vn/GFL2_CHARACTER_BROWSER.html>
- **📦 Dùng offline:** tải repo (Code → Download ZIP), giải nén, mở `index.html` — không cần server.

## Tính năng

- Danh sách 64 nhân vật, lọc theo **nguyên tố / class**, ô tìm kiếm nhanh.
- Trang chi tiết: kỹ năng (kèm chỉ số), Neural Helix, Vertebrae Upgrade, review + vũ khí đề xuất.
- **Đội hình đề xuất** cho từng nhân vật (đã research + verify đa nguồn, 08/2026) — tên đồng đội bấm
  được để nhảy sang trang nhân vật đó.
- Tab tra cứu **vũ khí** (187 khẩu, có ảnh, lọc theo loại).
- Light/dark theme, link chia sẻ dạng `#c=<Tên nhân vật>`.

## Nguồn dữ liệu

- Dữ liệu nhân vật/vũ khí: *GFL2 Official Release Info Compilation* (cộng đồng Discord chính thức).
- Đội hình: tổng hợp + kiểm chứng chéo từ Dexerto, Signal·Frontline, The Kon Network, gfl2.help và
  wiki CN (08/2026).
- Bản dịch tiếng Việt: thuật ngữ cơ chế giữ nguyên tiếng Anh để đối chiếu in-game.
